# Autoresearch (Karpathy 2026)

Autoresearch (Karpathy 2026)
Works very well for research with an “objective function” - can we optimize X?
Write code to solve a problem 
Write code to evaluate the solution
Write code to solve the problem again (refine the solution)
Uses loops to converge on a quantitative value
Set research on autopilot
Limitations:
Most research does not have a clearly defined “objective function”
AI has limited means for developing solutions (usually: use existing approaches)
Evaluation can be prejudiced, leading to confirmation bias
