## The 60-Column Grid

### FOUNDATIONS

A modular grid with 60 columns gives you division by 2, 3, 4, 5, 6, 10, 12, 15, 20, and 30. One system for every possible rhythm.

> "The grid system is an aid, not a guarantee. It permits a number of possible uses and each designer can look for a solution appropriate to his personal style." — Josef Müller-Brockmann

## Breaking the Grid

Wolfgang Weingart took the Swiss tradition and shattered it — not to destroy order, but to find new orders within the fragments.

- Overlapping forms create depth
- Diagonal energy disrupts the horizontal
- Transparency reveals what's behind
- The accident becomes the method

## Programmatic Design

Karl Gerstner proposed that design could be a programme — a set of rules that generates solutions. The designer writes the programme; the programme makes the design.

This is not automation. This is amplification.

---

## What Machines Dream

When we give a machine the vocabulary of Swiss design — grids, type scales, color systems, compositional rules — and then give it content to interpret, something unexpected happens.

The machine doesn't replicate. It interpolates. It finds configurations that a human designer might not reach, because it has no habits to break.
