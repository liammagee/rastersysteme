The Grid

One grid.
Any subdivision.

60 is divisible by 2, 3, 4, 5, 6, 10, 12, 15, 20, and 30. Paired with 40 rows on a 16:9 canvas, this single modular grid handles any layout without compromise.

Hierarchical guides at every 12th column (strong), every 5th (medium), and every column (fine) give you three levels of structural precision.

Compare

Three intensities.
One evaluation.

Run all three art-direction intensities against the same source. Claude evaluates each against a 100-point rubric covering content fidelity, design quality, accessibility, and narrative coherence.

Faithful
Muller-Brockmann
"The grid is a system of order for content."
Selects layouts, preserves structure. The content speaks; the grid organises.
Moderate
Gerstner
"To design is to plan and to arrange."
Restructures for impact, adds pacing. The programme shapes the message.
Radical
Weingart
"What's the use of being legible, when nothing inspires you to take notice?"
Fragments, reorders, disrupts. Radical design, not deletion. Every word survives.

Accessibility

Built-in QA checks every slide for contrast ratios, readability, and structural accessibility. Colour-coded pass/fail indicators.

Batched

Incremental Pipeline

Compose runs are batched and resumable. Crash mid-deck? Pick up where you left off. No wasted API calls.

Formats

PPTX + HTML + Review

One source, three outputs. PowerPoint for delivery, HTML for the web, review grids for validation. All pixel-identical.

Directives

Control layout, background, font, and intensity per-slide with HTML comments. Full creative control when you need it.

Quick Start

Three commands.
Swiss precision.

From Markdown to a fully art-directed presentation in under a minute. The pipeline handles layout selection, chromatic arcs, accessibility checks, and output generation. 

# Install
$ npm install

# Generate PPTX from Markdown
$ npm run raster -- slides.md --theme dark

# Claude-directed art direction
$ npm run compose -- slides.md --intensity radical

# 3-way comparison with evaluation
$ npm run compare -- slides.md --theme light

# Interactive studio viewer
$ npm run studio -- slides.html

# Accessibility audit
$ npm run qa -- slides.html
